# 格优代理端

独立的代理移动端仓库，默认入口为 AI接待、客户、电子讣告、遗照、套餐与报价。不提供总工作台、商城或平台管理导航。

```sh
npm ci
npm run dev
```

入口：<http://127.0.0.1:5197/#/agent>；`/__project`返回仓库真实目录和分支。旧工作台5187保持运行，不自动切换。

公开本地演示账号：`13900000000` / `Geyou2026!`。这不是生产账号体系。

```sh
npm test
npm run typecheck
npm run build
npm run verify
```

构建结果在`dist/`。静态文件不包含AI服务，`npm run preview`仅用于前端构建查看；完整本地功能由`npm run dev`挂载文本/讣告/图像/OCR网关。默认使用本机已有Codex登录；不复制密钥，环境变量见`.env.example`，配置放仓库根`.env.local`。OCR依赖macOS和系统Swift。

## 来源与后续维护

从`yufuxiang-geyou-prototype`的当前工作区拆出，基线提交`1b9b722`；包含当时尚未提交的代理功能与V1.2专项PRD。文件清单见`docs/extraction-manifest.json`。共享业务模型与页面组件作为本仓库内部源码维护，运行不依赖旧工程、外部软链或旧node_modules。总纲文档保留作历史背景，代理PRD为本项目需求真源。

原仓库、原服务与原数据不删除、不自动同步。新端口属于不同浏览器origin，旧5187的客户、聊天、照片和登录不会自动出现；迁移前须明确源数据并备份，不能覆盖已有资料。原端口尚在运行的图像任务也不迁移。

## 已知业务边界

套餐资料核对后直接进入项目、列表隐藏手机号已包含；讣告日期地点带入和办理后返回原聊天仍是待完善项，拆仓没有顺便修复。数据仍为浏览器本地原型；生产API、后端鉴权、跨设备保存和部署另行接入。生成不等于采用、发布、付款或家属确认。
